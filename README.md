# Murim: Sendero del Qi — Prototype 0.2
Prototipo Android/Godot 4 orientado a Dimensity 8300 Ultra.

## 0.2
- Movimiento 3D relativo a cámara.
- Sprint con consumo de Qi y regeneración.
- Esquiva con Qi.
- Combo base de 3 golpes y área de daño.
- Controles táctiles: joystick virtual por arrastre en mitad izquierda + Ataque/Esquiva/Correr.
- Renderer Mobile/Vulkan.
- Preset Android arm64.
- Workflow de GitHub Actions para generar APK de depuración en la nube.

Esta versión sigue usando geometría placeholder; los assets 3D se añadirán después de validar controles, combate y rendimiento.
